### 🛠️ Getting Started for Development

This project uses `bun` for fast, reliable package management.

#### 1. Install Dependencies
```bash
bun install
```

#### 2. Environment Variables
Copy `.env.example` to `.env.local` to set up your environment properties such as PostHog keys.
```bash
cp .env.example .env.local
```

#### 3. Run Development Server
```bash
bun --bun run dev
```

#### 4. Build for Production
```bash
bun --bun run build
```

#### 5. Code Quality
We enforce strict typing and unified formatting utilizing ESLint and Prettier.
```bash
bun run lint
bun run format
```
